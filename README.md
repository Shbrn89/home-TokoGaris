# home-TokoGaris

## FASSET — B2B Fashion Asset Marketplace Prototype

Prototype halaman marketplace **FASSET** (B2B Fashion Asset Marketplace), dibuat dalam HTML/CSS statis agar mudah diimpor ke Figma lewat plugin [html.to.design](https://www.figma.com/community/plugin/1159123024924461424/html-to-design).

### Halaman

| # | Halaman | File |
|---|---------|------|
| 1 | Home / Landing | `fasset-home.html` |
| 2 | Catalog / Browse | `fasset-catalog.html` |
| 3 | Design Detail + Licensing | `fasset-detail.html` |
| 4 | Checkout / License Agreement | `fasset-checkout.html` |
| 5 | Designer Dashboard / Upload | `fasset-dashboard.html` |

Styling bersama ada di `assets/fasset.css` (CSS variables untuk warna, radius, dsb).

Buka `index.html` untuk melihat daftar/navigasi seluruh halaman.

### Lihat secara online

Jika GitHub Pages diaktifkan untuk repo ini (Settings → Pages → Deploy from branch `main` / root), halaman dapat diakses di:

```
https://shbrn89.github.io/home-TokoGaris/
```

### Import ke Figma

1. Buka file HTML yang diinginkan (misal `fasset-home.html`) langsung di browser, atau lewat GitHub Pages di atas.
2. Salin URL halaman tersebut.
3. Di Figma, jalankan plugin **html.to.design**, tempel URL-nya, lalu import.
